⚙️ Setup Required

Your Google OAuth credentials are not yet configured.

1

Get Google Credentials

Visit Google Cloud Console

  • Create a new project
  • Enable Google Drive API & Google Picker API
  • Create OAuth 2.0 credentials (Web Application)
  • Set redirect URI: {{ redirectUri }}
2

Update Configuration

Edit src/app/config/google.config.ts:

export const GOOGLE_CONFIG = {{
  GOOGLE_CLIENT_ID: 'your-client-id.apps.googleusercontent.com',
  GOOGLE_CLIENT_SECRET: 'your-client-secret',
  GOOGLE_PICKER_API_KEY: 'your-api-key',
  SERVICE_ACCOUNT_EMAIL: 'your-service-account@project.iam.gserviceaccount.com'
}}
3

Restart & Test

After updating the config:

  • Restart the development server (npm start)
  • Refresh this page in your browser
  • Click "Connect Google Account" to test
